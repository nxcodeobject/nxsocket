Kenapa NxSocket?

⟡

20+ modul siap pakai

Chat, presence, notifikasi, tracking, AI, terminal, WebRTC, meeting, feed, grup, OTP, media — tanpa membangun dari nol.

🛡

Gateway token

Akses lewat Endpoint Gateway dengan token per-user: expiry, scope, dan ACL room. Bisa di-regenerate atau dicabut.

⇄

Koneksi yang tahan putus

Heartbeat, reconnect, dan session resume — client kembali ke room yang sama tanpa memulai ulang percakapan.

🗄

Adapter data fleksibel

SQLite (default, lokal), Firebase (cloud), atau JSON ringan. Ganti lewat satu flag CLI atau environment variable.

🎥

Suara & video

Panggilan 1:1, grup mesh, sampai meeting skala besar via SFU LiveKit. Signaling WebRTC sudah termasuk.

⌘

Uji langsung dari HP

Server HTTPS self-signed + QR di terminal. Scan dari HP, mic dan kamera langsung jalan.

Arsitektur

Client tidak menyentuh server secara langsung

Semua akses masuk melalui Endpoint Gateway — validasi token, lalu diteruskan ke NxSocket Server yang mengelola koneksi, session, room, dan event.

  • Token per-user dengan scope dan expiry
  • ACL room — client hanya boleh masuk room yang diizinkan
  • Adapter SQLite / Firebase / JSON untuk penyimpanan
  • Rate limit per koneksi (default 60 pesan / 10 detik)

Cara mulai

  1. Pasang CLI

    cd D:\Framework\CLI\NxSocket
npm install
npm run build
npm link

    Setelah mengubah kode, jalankan npm run build lagi.

  2. Lihat endpoint & token

    nxsocket gateway info

    Menampilkan URL lokal, URL jaringan, dan token gateway.

  3. Jalankan server

    nxsocket server
nxsocket server --https   # mic & kamera di HP

    Default: port 7080, path /v1, adapter SQLite.

  4. Buka demo

    http://127.0.0.1:7080/v1/demo

    Atau uji semua modul dari CLI: npm run example:demo.

Client API

import { NxSocketClient } from "nxsocket";

const client = new NxSocketClient({
  url: "http://127.0.0.1:7080/v1",
  token: "<gateway-token>",
  reconnect: true,
});

client.on("welcome", (sessionId) => {
  client.join("lobby");
  client.broadcast("lobby", "chat", { text: "halo" });
});

client.connect();

Perintah CLI

Server

nxsocket server
nxsocket server --port 3090 --host 127.0.0.1
nxsocket server --adapter sqlite
nxsocket server --adapter firebase

Gateway & token

nxsocket gateway info
nxsocket gateway qr
nxsocket gateway token create --label alice --expires 7d
nxsocket gateway token list
nxsocket gateway token regenerate <id>
nxsocket gateway token revoke <id>

Pertanyaan umum

Butuh Node.js versi berapa?

Node.js 22 atau lebih baru.

Port 7080 sudah dipakai (EADDRINUSE)?

Matikan proses lama atau ganti port: nxsocket server --port 3090.

Connect gagal dengan 401?

Token salah, sudah di-regenerate, atau di-revoke. Buat/ambil token baru lewat nxsocket gateway token list.

Token berbeda tiap folder?

Folder data/ mengikuti direktori kerja (cwd). Samakan dengan flag --data-dir atau jalankan dari folder proyek yang sama.

Panggilan tersambung tapi tidak ada suara?

Pakai nxsocket server --https (bukan HTTP), izinkan mic di kedua perangkat, lalu ketuk tombol "Aktifkan suara" di halaman.

Bisa diakses dari luar rumah?

Ya — lewat Cloudflare Tunnel (npm run tunnel), Tailscale, atau reverse proxy seperti Caddy/Nginx di depannya.
